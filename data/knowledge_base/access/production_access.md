# Production Access Requests

Use this runbook when an employee asks for access to Snowflake production, Grafana dashboards, Jenkins production jobs, Tableau reporting, or other sensitive systems.

Diagnostic steps:

1. Identify requested systems and environments.
2. Look up employee team, role, manager, and current access groups.
3. Ask for business justification and urgency if missing.
4. Evaluate policy for each requested action.

Agent-authorized actions:

- Explain required approvals.
- Confirm current access groups.
- Collect justification, urgency, manager, and requested systems for handoff.

Not authorized:

- Grant production database access.
- Grant dashboard access that exposes operational or customer data.
- Approve privileged access.
- Bypass manager, data owner, service owner, or security approval.

Escalation should include requested systems, environments, justification, urgency, current groups, manager, and policy rationale.
